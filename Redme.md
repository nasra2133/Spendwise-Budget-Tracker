# SpendWise - Budget Tracker

## Project Description
SpendWise is a simple budget tracking application

## JavaScript Concepts Implemented

### 1. Variables
Variables store the monthly budget, total expenses
and remaining balance.

### 2. Data Types
The project uses numbers and strings to store information.

### 3. User Input
The prompt() function collects the user's budget
and total expenses.

### 4. Calculations
The application subtracts total expenses from
the monthly budget to calculate the remaining balance.

### 5. Functions
The calculateBalance() function performs budget calculations.
The displayResults() function displays the results.

### 6. Output
The console.log() function displays the budget summary
in the browser console.

## How to Run the Project
1. Open index.html using Live Server.
2. Enter your monthly budget.
3. Enter your total expenses.
4. Open the browser console to view the results.
